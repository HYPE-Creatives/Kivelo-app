                        🔗 API CONFIGURATION
================================================================================

Base URLs (with automatic fallback):
- Development: http://localhost:5000/api/v1
- Production:  https://family-wellness.onrender.com/api/v1

Content-Type: application/json
Authentication: Bearer Token (JWT)

RECOMMENDED PATTERN - API URLs with Fallback:
--------------------------------------------------------------------------------

```typescript
// In development, try local first then remote
// In production, only use remote

const isProduction = Platform.OS === 'web' && 
  typeof window !== 'undefined' && 
  !window.location.hostname.includes('localhost');

const API_URLS = isProduction
  ? ["https://family-wellness.onrender.com/api/v1"]
  : [
      "http://localhost:5000/api/v1",
      "https://family-wellness.onrender.com/api/v1",
    ];
```

================================================================================
                        📡 API HELPER FUNCTION
================================================================================

Use this pattern in all contexts for API calls with automatic fallback:

```typescript
import AsyncStorage from "@react-native-async-storage/async-storage";

const ACCESS_TOKEN_KEY = "kivelo_access_token";

const apiCallWithFallback = async (
  endpoint: string, 
  options: RequestInit = {}
): Promise<{ response: Response; data: any }> => {
  let lastError = null;
  
  for (const baseUrl of API_URLS) {
    try {
      console.log(`🔄 Trying: ${baseUrl}${endpoint}`);
      
      const response = await fetch(`${baseUrl}${endpoint}`, options);
      
      if (!response.ok) {
        let errorMessage = `HTTP ${response.status}`;
        try {
          const errorData = await response.json();
          errorMessage = errorData.message || errorMessage;
        } catch {
          errorMessage = response.statusText || errorMessage;
        }
        
        // For 404 or 5xx errors, try next URL
        if (response.status === 404 || response.status >= 500) {
          lastError = { success: false, message: errorMessage };
          console.warn(`⚠️ Route not found or server error at ${baseUrl}:`, errorMessage);
          continue;
        }
        
        // For 4xx errors (auth/validation), throw immediately
        throw new Error(errorMessage);
      }

      const data = await response.json();
      console.log(`✅ Success with: ${baseUrl}`);
      return { response, data };
      
    } catch (error: any) {
      // If it's our thrown error (client error), re-throw it immediately
      if (!error.message?.includes('Network') && !error.message?.includes('fetch')) {
        throw error;
      }
      
      lastError = {
        success: false,
        message: `Network error: ${error.message}`
      };
      console.warn(`🌐 Network error with ${baseUrl}:`, error.message);
    }
  }

  throw new Error(lastError?.message || "Unable to connect to server");
};
```

--------------------------------------------------------------------------------
AUTHENTICATED REQUEST HELPER (for protected endpoints):
--------------------------------------------------------------------------------

```typescript
const makeAuthenticatedRequest = async (
  endpoint: string,
  options: RequestInit = {}
): Promise<{ response: Response; data: any }> => {
  const token = await AsyncStorage.getItem(ACCESS_TOKEN_KEY);
  
  if (!token) {
    throw new Error("Not authenticated. Please log in again.");
  }

  return apiCallWithFallback(endpoint, {
    ...options,
    headers: {
      "Content-Type": "application/json",
      "Authorization": `Bearer ${token}`,
      ...options.headers,
    },
  });
};
```

    "role": "parent"

Frontend Implementation:
```typescript
const registerParent = async (
  email: string,
  password: string,
  name: string,
  phone: string,
  dob: string,
  termsAccepted: boolean
) => {
  try {
    const { data } = await apiCallWithFallback("/auth/register-parent", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        name: name.trim(),
        email: email.trim().toLowerCase(),
        password,
        phone: phone.trim(),
        dob,
        termsAccepted,
      }),
    });

    if (data.success) {
      const userData = data.data?.user || data.user;
      const tokens = {
        accessToken: data.accessToken || data.token,
        refreshToken: data.refreshToken || "",
      };
      
      // Store auth data
      await AsyncStorage.setItem(USER_STORAGE_KEY, JSON.stringify(userData));
      await AsyncStorage.setItem(ACCESS_TOKEN_KEY, tokens.accessToken);
      
      return { success: true, message: "Registration successful!" };
    }
    return { success: false, message: data.message };
  } catch (error: any) {
    return { success: false, message: error.message || "Registration failed" };
  }
};
```

```typescript
  try {
    const { data } = await apiCallWithFallback("/auth/parent-login", {

        refreshToken: data.refreshToken || "",

      await AsyncStorage.setItem(USER_STORAGE_KEY, JSON.stringify(finalUser));
      await AsyncStorage.setItem(ACCESS_TOKEN_KEY, tokens.accessToken);

      return { success: true, message: "Login successful!" };
    }
    return { success: false, message: data.message };
  } catch (error: any) {
    return { success: false, message: error.message };
  }
};
```

Frontend Implementation:
```typescript
const setChildPassword = async (password: string) => {
  try {
    const token = await AsyncStorage.getItem(ACCESS_TOKEN_KEY);
    
    const { data } = await apiCallWithFallback("/auth/set-child-password", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${token}`,
      },
      body: JSON.stringify({ password }),
    });

    if (data.success) {
      // Update stored token if new one provided
      if (data.token) {
        await AsyncStorage.setItem(ACCESS_TOKEN_KEY, data.token);
      }
      
      // Update user to mark hasSetPassword = true
      const storedUser = await AsyncStorage.getItem(USER_STORAGE_KEY);
      if (storedUser) {
        const user = JSON.parse(storedUser);
        user.hasSetPassword = true;
        await AsyncStorage.setItem(USER_STORAGE_KEY, JSON.stringify(user));
      }

      return { success: true, message: "Password set successfully!" };
    }
    return { success: false, message: data.message };
  } catch (error: any) {
    return { success: false, message: error.message };
  }
};
```

```typescript
const logout = async () => {

    // Clear all stored auth data
    await Promise.all([
      AsyncStorage.removeItem(USER_STORAGE_KEY),
      AsyncStorage.removeItem(ACCESS_TOKEN_KEY),
```

```typescript
const completeActivity = async (activityId: string) => {
  try {
    const token = await AsyncStorage.getItem(ACCESS_TOKEN_KEY);
    if (!token) throw new Error("Not authenticated");

    const { data } = await apiCallWithFallback(`/activity/${activityId}/complete`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`,
      },
    });

    if (data.success) {
      // Refresh gamification stats after completing
      await refreshStats();
      return { success: true };
    }
    throw new Error(data.message);
  } catch (error: any) {
    return { success: false, message: error.message };
  }
};
```

================================================================================
                    ⚠️ ERROR HANDLING PATTERNS
================================================================================

Standard Error Response Format:
{
  "success": false,
  "message": "Error description"
}

HTTP Status Codes:
- 400: Bad Request (validation errors)
- 401: Unauthorized (no token or invalid token)
- 403: Forbidden (role mismatch)
- 404: Not Found (resource doesn't exist)
- 409: Conflict (duplicate resource)
- 500: Internal Server Error

Frontend Error Handling Pattern:
```typescript
const handleApiCall = async () => {
  try {
    const result = await someApiCall();
    
    if (!result.success) {
      // Show error toast/alert
      Alert.alert("Error", result.message || "Something went wrong");
      return;
    }
    
    // Handle success
  } catch (error: any) {
    // Network or unexpected errors
    Alert.alert("Error", error.message || "Network error. Please try again.");
  }
};
```

                    🔄 RECOMMENDED CONTEXT STRUCTURE
================================================================================

For React Native/Expo apps, organize API calls into Context Providers:

1. AuthContext.tsx
   - login, logout, register
   - changePassword, setChildPassword
   - refreshProfile, clearAuthState

2. MoodContext.tsx (Child features)
   - submitMood, getMoodHistory
   - getTodayMood, getMoodStats
   - updateMood, deleteMood

3. GamificationContext.tsx (Child features)
   - getStats, getBadges
   - redeemReward, refreshStats

4. ActivityContext.tsx
   - getActivities, createActivity (parent)
   - completeActivity (child)
   - updateActivity, deleteActivity (parent)

5. LearningContext.tsx
   - getArticles, getArticle
   - markComplete

Example Provider Wrapper (in _layout.tsx):
```typescript
<AuthProvider>
  <MoodProvider>
    <GamificationProvider>
      <ActivityProvider>
        <LearningProvider>
          {children}
        </LearningProvider>
      </ActivityProvider>
    </GamificationProvider>
  </MoodProvider>
</AuthProvider>
```
